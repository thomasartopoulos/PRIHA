# Imágenes del sitio

| Archivo | Uso |
|---|---|
| `logo_priha.jpg` | Logotipo sobre fondo claro (header) |
| `logo_priha_blanco.png` | Logotipo blanco horizontal (portada desde 640 px, footer) |
| `logo_priha_blanco_apilado.png` | Logotipo blanco apilado (portada en teléfono) |
| `logo_fce.png` | Sello de la Facultad, recortado del original naranja |
| `og-priha.jpg` | Vista previa 1200×630 para redes sociales |
| `novedades/` | Fotos de las tarjetas de Novedades |
| `_originales/` | Archivos fuente sin procesar. No se usan en el sitio. |

## Novedades

Cada novedad necesita su imagen en `novedades/` con el nombre que figura
en el JSON `#nov-datos` de `index.html`. Proporción recomendada 124:100
(por ejemplo 744×600 px). Si falta, la tarjeta muestra un ícono gris.
